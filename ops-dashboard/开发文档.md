# 🖥️ 多任务监控可视化实时大屏 — 开发文档

> **目标**: 5 屏联动, 实时可视化 Hermes / VS Code(Cline) / 极空间Z2S / 欧易交易 的运行状态
> **核心体验**: 一眼看到 — 谁在干活、正在干什么、什么还没干、可学习还是可行动
> **版本**: v1.0 | 日期: 2026-08-06

---

## 一、总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      🖥️ 5屏大屏总控台                        │
│                                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │ ① Hermes  │  │ ③ VS Code │  │ ⑤ 控制中台 │  │ ② 极空间  │   │
```

### 五屏布局 (推荐 1920×1080 或 4K)

| 屏位 | 名称 | 内容 | 数据源 |
|------|------|------|--------|
| 左上 | **① Hermes 状态** | Agent 运行状态、模型调用、任务队列、token消耗 | Hermes API / agent.log |
| 右上 | **② 极空间 Z2S** | NAS 运行、Docker容器、存储、网络 | SSH + Docker API (192.168.1.3:10022) |

| 中间 | **⑤ 控制中台** | 欧易交易 + 全局控制 + 各系统心跳 | OKX API / 控制指令 |

## 二、各屏详细设计

### ① Hermes 状态大屏

**数据来源**: 
- Hermes Studio API (`/api/hermes/...`)
- `~/.hermes/logs/agent.log` (模型调用统计)

**显示内容**:
```
┌─ Hermes Agent ─────────────────────────────┐
│ 🤖 状态: 🟢 运行中 (PID xxx)                │
│ 🧠 当前模型: deepseek-v4-flash (调用中🔥)    │
│ 📊 今日调用: 1442 次 | tokens 2.5亿         │
│ 💰 消耗: DeepSeek ¥95.73 / OpenRouter ¥0   │
│ 📋 任务队列: [3个待办] [2个执行中] [1个排队]  │
│ ⚡ 活跃度: 模型🔥 任务⚡ 知识库📚             │
└────────────────────────────────────────────┘
```

**关键指标**: 模型调用活跃度(3min内)、任务队列、token消耗、错误率

### ② 极空间 Z2S 大屏

**数据来源**: SSH 连接 `192.168.1.3:10022` (用户 18577260181)

**采集命令** (SSH 执行):
```bash
# 系统状态
uname -a && uptime && free -h && df -h

# Docker 容器 (如果极空间装了 docker)
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 微信快存目录 / Hermes 存储
ls -lt /vol1/1000/.../knowledge-base/inbox/ 2>/dev/null | head

# 网络
ip addr | grep inet
```

**显示内容**:

**⚠️ 网络问题**: 主控(192.168.110.x)与极空间(192.168.1.x)不同网段

1. **SSH 隧道**: 主控 `ssh -f -N -L 10022:192.168.1.3:22 user@极空间网关`
2. **异地组网**: 极空间自带"异地组网"功能 (Z-Connect / Tailscale)
3. **同网段**: 极空间接主控路由器, 或主控加路由表

## 三、数据采集层设计

```
┌─────────── 数据采集层 (collectors/) ───────────┐
│                                                │
│  collector_hermes.py   ← Hermes API + agent.log │
│  collector_zspace.py   ← SSH + Docker API       │
│  collector_vscode.py   ← Cline tasks + VS Code  │
│  collector_okx.py      ← OKX API (已有)         │
│  collector_events.py   ← 统一事件总线           │
│                                                │
│  每个 collector 独立进程, 写入共享状态           │
└────────────────────────────────────────────────┘
                    ↓ JSON
┌─────────── 状态聚合层 (state/) ────────────────┐
│  state.json (统一快照, 3秒刷新)                 │
│  events.jsonl (事件流, 滚动1000条)             │
└────────────────────────────────────────────────┘
                    ↓ HTTP/WS
┌─────────── 前端大屏 (web/) ────────────────────┐
│  index.html + app.js + style.css               │
│  5屏布局, WebSocket 实时推送                    │
└────────────────────────────────────────────────┘
```

### 技术栈选择

| 层 | 技术 | 理由 |
|----|------|------|
| 后端 | Python + Flask (已有) | 复用 dashboard.py 经验 |
| 实时推送 | WebSocket (flask-sock) | 双向实时, 优于轮询 |
| 前端 | 原生 JS + CSS3 动画 | 轻量, 无构建 |
| SSH | paramiko | Python SSH 库 |
| Docker | docker SDK for Python | 容器监控 |
| 数据 | JSON + JSONL 文件 | 简单可靠, 无数据库 |

## 四、动画与可视化设计

### 动画语言 (让"在干什么"一眼可见)

| 状态 | 动画 | 含义 |
|------|------|------|
| 🟢 活跃 | 呼吸发光 + 扫描线 | 正在干活 |
| 🔵 空闲 | 淡蓝色静态 | 待命 |
| 🟡 缓慢 | 黄色脉冲 (慢速) | 卡顿/延迟 |
| 🔴 异常 | 红色闪烁 + 告警音 | 出问题 |
| ⚪ 未启动 | 灰色暗化 | 还没干 |
| ⚡ 队列中 | 顺时针旋转图标 | 排队等待 |

### 关键动画特效

```css
/* 活跃: 呼吸发光 */
@keyframes breathe {
  0%,100% { box-shadow: 0 0 8px rgba(16,185,129,.3); }
  50%     { box-shadow: 0 0 24px rgba(16,185,129,.7); }
}
.active { animation: breathe 1.6s infinite; }

/* 扫描线 (正在处理) */
@keyframes scan {
  0%   { top: -40px; }
  100% { top: 100%; }
}
.scanning::after { animation: scan 2.2s linear infinite; }

/* 数据流动 (网络/传输) */
@keyframes flow {
  0%   { stroke-dashoffset: 1000; }
  100% { stroke-dashoffset: 0; }
}

/* 打字机效果 (Cline 输出) */
@keyframes typing { from { width: 0 } to { width: 100% } }
```

### 每个数据点的动画映射

| 数据 | 动画触发 |
|------|----------|
| 模型调用 | 模型卡片红色呼吸 + "🔥" |
| 新任务 | 任务卡片弹入 + 数字跳动 |
| 代码提交 | VS Code 屏绿色闪光 |
| 容器重启 | 极空间屏图标旋转 |
| OKX 成交 | 交易面板金色闪光 + 金额滚动 |
| 网络异常 | 对应屏红色闪烁 |

## 十、核心体验验收标准

1. **3秒内** 大屏任一子系统状态刷新
2. **一眼区分**: 🟢干活 / 🔵待命 / 🔴异常 / ⚪未干
3. **事件流** 实时滚动, 关键事件高亮
4. **欧易交易** 成交/挂单变化金色闪光提示
5. **极空间** 容器/存储/微信快存可视
6. **Cline** 任务进度条 + 正在执行的模型
7. **中间控制台** 可一键跳转/控制
